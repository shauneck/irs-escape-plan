
# 📦 IRS Escape Plan – Emergent App Prompts & Logic

This repository contains the full prompt and logic architecture for building **The IRS Escape Plan** platform inside [Emergent.sh](https://emergent.sh).

---

## 📘 What This Project Is

**The IRS Escape Plan** is an AI-driven tax strategy education platform designed for:
- High-income W-2 earners
- Business owners
- Real estate investors

This app is being built inside the Emergent no-code/AI automation platform, with support for:
- Multi-course structures
- Tax glossary with quiz mode
- Personalized dashboards
- Filtering logic
- Community, gamification, and tax-saving tools

---

## 📁 Files in This Repo

| File | Purpose |
|------|---------|
| `IRS-Escape-Plan-Emergent-Prompts.txt` | All core Emergent prompts in human-readable format (homepage, navigation, quiz, glossary logic, etc.) |
| `irs_escape_plan_glossary.json` | Structured JSON version of all 20 glossary terms with case studies (for direct use in Emergent or apps) |
| `irs_escape_plan_glossary_backup.txt` | Human-readable glossary export (JSON blocks as plain text for manual inspection) |

---

## 🔧 How to Use

### Reimport into Emergent
1. Open [https://emergent.sh](https://emergent.sh)
2. Create a new project
3. Paste prompts one-by-one from `IRS-Escape-Plan-Emergent-Prompts.txt`
4. Use JSON blocks (glossary, filters) from `irs_escape_plan_glossary.json` as needed

### Restore/extend manually
You can also rebuild the logic in other systems using the `.json` and `.txt` formats.
